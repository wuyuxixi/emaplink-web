# ZSAC 透明渲染素材与交付

2026-10-18，以已确认的首屏设计图 `../hero-reference.png` 为主参考，使用内置 image_gen 分别生成五张透明底素材，再通过 Sharp 输出响应式 WebP。未使用 CLI/API 生图，也未引入 Canvas 或 Three.js。

## 素材

| PNG 母版 | 用途 | WebP 尺寸 |
| --- | --- | --- |
| gateway.png | 透明罩、盾牌、蓝白分层网关 | 480 / 800 / 1200 px |
| phone.png | 手机与透明底座 | 240 / 480 / 720 px |
| drone.png | 无人机与透明底座 | 240 / 480 / 720 px |
| camera.png | 执法记录仪与透明底座 | 240 / 480 / 720 px |
| helmet.png | 智能头盔与透明底座 | 240 / 480 / 720 px |

五张母版均为 1536×1024 RGBA。保留透明度、边缘高光和半透明投影，没有在网页上叠加白色图片矩形或额外 CSS 底座。

网页素材位于 `public/images/products/zsac-gateway/renders/`。PNG 母版只存放在本文档目录，不进入网站 public，也不随页面下载。

完整生成提示词：[prompts.json](./prompts.json)。参考链：网关参考首屏图；手机参考首屏图与网关；另外三类终端参考首屏图与手机，以统一材质、光照和底座。

## 优化与运行

运行 `node scripts/prepare-zsac-renders.mjs` 可从母版重新生成全部交付尺寸。脚本验证真实 alpha 通道，采用 WebP quality 88 / alphaQuality 94，不改变构图。各文件的尺寸与体积见 [delivery-manifest.json](./delivery-manifest.json)。

- 每个素材各取最大尺寸时，共 232,340 bytes（约 227 KiB）；实际页面按显示尺寸与 DPR 选择资源。
- 桌面 DPR 1 首屏选用 gateway-800 及四张 480，共 132,394 bytes（约 129 KiB）。
- 320px / DPR 1 首屏选用 gateway-480 及四张 240，共 58,822 bytes（约 57 KiB）。
- 以上仅为五张视觉素材的文件体积，不代表整个页面传输量或实测加载时间。
- 首屏图片直接出现在 HTML 中。中央网关使用 high fetch priority，设备图片立即加载；架构区图片懒加载。
- 连线保持 SVG；标签、说明、按钮保持 HTML。终端切换和键盘操作沿用原实现。
- GSAP 管理分层入场、物件轻浮动、SVG 信号流与桌面鼠标视差。IntersectionObserver 在首屏图形离开视口时暂停循环；标签页隐藏也暂停；减少动态效果模式还原静态图。
- 主视觉是预渲染素材加轻量空间动效，不支持自由旋转。

## 验证

- Astro 检查：76 个文件，0 errors / warnings / hints。
- 静态构建：148 页成功。
- 浏览器回归：14 项通过，新增离屏暂停与减少动态效果还原检查。
- 浏览器截图已检查：1365×768、1440、768、390、320px，其中桌面及手机验证 DPR 2。
- 所有五张首屏图均完成解码；无脚本模式可显示；上述宽度无横向溢出，无页面脚本错误。

与初版相比，主要修正的是素材品质：用带实际曲面、镜头、反射和遮挡关系的渲染图替换了简化线稿。首屏与架构区共享素材，保留原有页面内容与全站页脚。
