# 联易软件网站改版记录

分支：`codex/premium-site-redesign`

## 设计依据

用户指定使用 `redesign-skill` 与 `soft-skill`，保留 Astro、Tailwind v4、现有路由、内容与功能。

采用 soft-skill 的 Soft Structuralism + Editorial Split：银白与蓝灰表面、墨色文字、品牌蓝、悬浮岛式导航、双层外框和内核、圆形嵌套箭头按钮。附加的 design-taste-frontend 抽签方向为 One motif，seed `1521658550`；圆角密码模块是贯穿首页的形状。

两份用户指定技能优先于附加视觉检查技能：保留 soft-skill 明确要求的眉题、悬浮导航、内高光与物理层次。没有为迎合检查器删除这些设计。对应的渲染检查使用显式 allow 参数，源码 lint 仍提示 6 处眉题。

核心想法：把联易 ZSAC 软密码模块画成一枚连接设备、用户和应用的可信内核。它是机制示意，不是产品硬件照片或实时管理界面。

## 首页内容论证

- 从终端到云建立可信连接 → ZSAC 核心与三个接入对象的机制示意。
- 管理对象共享密码信任链 → 设备、用户、应用、授权四项能力。
- 产品覆盖不同接入环节 → 四款真实产品、原有产品插图与详情入口。
- 方案按场景组合 → 三类真实方案与可切换的示意图、摘要；无 JavaScript 时三个详情入口仍可访问。
- 安全兼顾部署与服务 → 原有安全、易用、合规、经济主张和服务内容。
- 内容持续更新 → 从现有新闻集合读取最新三篇文章。
- 咨询有明确入口 → 真实联系页、电话与邮箱。

未新增客户背书、经营统计、认证结论或假实时数据；服务承诺沿用现有数据。没有待替换的虚构示例内容。

## 主要改动

- 重做首页构图、产品卡片、场景切换、服务区与新闻列表。
- 统一全站导航、页头、页脚、联系区、按钮、色彩和字体。
- 产品、方案、关于、文化、联系与 404 页采用同一浅色系统。
- 产品与方案页展示经过目视确认的相关示意图；未把原名为 gateway/diagram.webp 的城市背景当成架构图。
- IntersectionObserver 分段入场、核心轻浮动、路径透明度变化、悬浮和按压反馈；支持减少动态效果，脚本关闭时正文仍可阅读。
- 桌面导航显示当前位置，保留移动菜单、搜索、分页、文章目录和证书灯箱。

## 素材

- 首页核心：HTML、CSS 和项目自有轻线条 SVG 图标，不是生成的产品照片。
- 产品插图：沿用 `public/images/products/*/banner.webp` 四张既有图，降低饱和度以适配新色彩。它们的旧版插画语言仍是视觉一致性的主要限制。
- 方案插图：沿用 `public/images/solutions/*/banner.webp`，保留内容语义。
- gateway 产品页复用多形态终端方案示意，server 产品页使用已核实的原有接入架构图。
- 不引入第三方照片或视频，不把通用素材当作客户现场。
- Manrope 拉丁可变字体本地托管；中文使用系统中文字体。来源为 Google Fonts，许可证在 `public/fonts/OFL-Manrope.txt`，无需运行时请求字体服务。
