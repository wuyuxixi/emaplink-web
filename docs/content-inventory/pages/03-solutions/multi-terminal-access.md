## 市场需求
1. 随着移动产业、物联网产业的高速发展，移动终端、物联网感知终端在各个行业进行了大规模的部署和应用。与此同时，物联网终端的安全问题也越来越突出，如何对终端的身份和行为进行认证和管控，实现设备的安全接入和安全应用，成为行业的共识。
2. 联易软件推出的“多形态终端安全接入”方案，基于先进的 ZSAC 接入安全机制，以创新的密码算法实现软密码身份模块，具有终端普遍适配、安全合规、性能可靠、成本低廉等明显优势，可满足不同终端设备的安全接入需求。
- 适用行业（前 6 个）：金融、能源、工业、电力、交通、大型国央企。

## 方案思路
方案以软密码模块的双向认证实现终端准入控制，能够适配各类物联网终端，覆盖终端身份、行为与流量的持续校验。
- 3 项能力：
  | 能力 | 描述 |
  |---|---|
  | 持续认证 | 对终端身份与行为进行持续校验。 |
  | 实时阻断 | 发现异常终端与异常行为即时阻断。 |
  | 全流量接入 | 覆盖终端全流量接入与管控。 |

## 方案应用（3 项）
| 标题 | 描述 |
|---|---|
| 轻松适配 | 待接入终端设备集成适配软密码模块 SDK，SDK 大小 20K，运行空间 500K，可轻松运行于各类终端设备中。 |
| 安全管控 | 软密码模块 SDK 与配套的安全网关，基于双向认证实现设备的身份识别及准入管控。 |
| 无缝融合 | 可与客户已有的用户管理、设备管理系统进行对接集成。 |

## 适用场景
多形态终端安全接入解决方案，以软密码模块的双向认证实现终端准入控制，能够适配各类物联网终端，可以应用在金融、能源、工业、电力、交通、大型国央企、政务、应急、环保、公安等实现物联网终端安全接入场景。
- 行业标签：金融、能源、工业、电力、交通、大型国央企、政务、应急、环保、公安。
